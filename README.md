# Тестировщик ПО (Desktop-приложения) — тестовое задание

Проверка десктоп-приложения, отображающего сигналы от сервиса по TCP (порт 2001).
Содержит: чек-лист, обоснование критичного сценария и автотесты на Python.

## 1. Чек-лист (15 пунктов)

| # | Проверка | Приоритет |
|---|----------|-----------|
| 1 | Приложение запускается, главное окно содержит таблицу (ID, имя, значение, качество, время), кнопки «Подключиться» и «Обновить» | High |
| 2 | **Подключение при доступном сервисе: после «Подключиться» в таблице появляются все 10 сигналов** | **Critical** |
| 3 | Каждая строка заполнена корректно: уникальный ID, непустое имя, числовое значение, допустимое качество, актуальная метка времени | Critical |
| 4 | Значения обновляются автоматически: синусоидальные и случайные сигналы меняются со временем | High |
| 5 | «Обновить» запрашивает свежие значения; таблица и метки времени обновляются | High |
| 6 | Подключение при недоступном сервисе (сервис остановлен): понятное сообщение, приложение не зависает и не падает | High |
| 7 | Потеря связи во время работы (остановка симулятора): индикация потери связи, значения не выглядят «живыми» | Critical |
| 8 | Повторное подключение после обрыва: данные возобновляются без перезапуска приложения | High |
| 9 | Повторное нажатие «Подключиться» при активном соединении не создаёт дублей соединений и строк | Medium |
| 10 | «Обновить» без установленного соединения: корректная реакция (кнопка неактивна или сообщение) | Medium |
| 11 | Отображение качества (GOOD/BAD/UNCERTAIN): значение качества соответствует присланному, плохое качество визуально выделено | High |
| 12 | Некорректные данные от сервиса (битый JSON, NaN, пропущенное поле, дублирующийся ID): приложение не падает, ошибка обрабатывается | High |
| 13 | Формат и точность отображения: числа, единый формат времени, часовой пояс, длинные имена не ломают таблицу | Medium |
| 14 | Производительность и стабильность: длительная работа (≥1 ч), нет роста памяти и «подвисаний» UI при частых обновлениях | Medium |
| 15 | Юзабилити окна: изменение размера, сортировка и прокрутка таблицы, корректное закрытие с разрывом соединения | Low |
