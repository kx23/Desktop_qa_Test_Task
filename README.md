# Тестировщик ПО (Desktop-приложения) — тестовое задание

Проверка десктоп-приложения, отображающего сигналы от сервиса по TCP (порт 2001).
Содержит: чек-лист, обоснование критичного сценария и автотесты на Python.

## 2. Самый критичный сценарий и почему

**Сценарий:** Подключение при доступном сервисе: после подключения в таблице появляются все 10 сигналов

**Обоснование:** Это ключевая функция приложения. Если подключение не работает или сигналы приходят неполными/искажёнными, остальная функциональность (обновление, обработка обрывов) теряет смысл. В системе управления неверная картина процесса будет самым дорогим дефектом. Сценарий также самый быстрый smoke-индикатор здоровья всей цепочки "сервис → сокет → приложение".

## 3. Структура проекта

```
signal-monitor-autotests/
├── config/settings.py            # конфигурация (env-переменные)
├── framework/
│   ├── client.py                 # TCP-клиент сервиса (единственное место, знающее протокол)
│   ├── models.py                 # модель Signal + строгий разбор/валидация
│   └── simulator_process.py      # запуск/остановка симулятора отдельным процессом
├── simulator/signal_simulator.py # сервис-симулятор: 10 сигналов, порт 2001
├── tests/
│   ├── conftest.py               # фикстуры: симулятор (session), клиент (function)
│   └── test_connect_and_receive_signals.py
├── pytest.ini                    # маркеры, таймаут, логирование
├── requirements.txt
└── README.md
```

## 4. Инструкция по запуску

Требования: Python 3.10+.

```bash
# создание окружения
python -m venv .venv
# Linux/macOS:
source .venv/bin/activate
# Windows (PowerShell):
.venv\Scripts\Activate.ps1

# Загрузка зависимострей
pip install -r requirements.txt

pytest                                   # все тесты
pytest -m critical                       # только критичные
pytest --html=reports/report.html --self-contained-html   # HTML-отчёт
```

## 5. Что проверяют автотесты

| Тест | Что проверяет                                                                                                       |
|------|---------------------------------------------------------------------------------------------------------------------|
| `test_connect_receives_full_valid_signal_set` | Критичный сценарий: Подключение при доступном сервисе: после подключения в таблице появляются все 10 сигналов |
